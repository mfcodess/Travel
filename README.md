# Travel

Створено за допомогою фреймворку SwiftUI. На розробку проєкту знадобилося близько 4 тижнів.

Ідея була взята з уже існуючого проєкту, який свого часу не був завершений. Я вирішив повернутися до цієї ідеї, переробити її та використати як практику для розвитку навичок в iOS-розробці. У цьому застосунку реалізовано роботу з Firebase та використано архітектуру MVVM.

У результаті вийшов досить цікавий застосунок, який став хорошою практикою роботи зі SwiftUI, анімаціями, екранами, Firabase, MVVM.
